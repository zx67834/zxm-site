接下来跑了一天业务，去了云软件谷、红莲等相关产业园，走访企业。||说是产业园，感觉像鬼楼一样|| 一个园区十几栋楼，每栋就三四家企业。~~按照我的刻板印象来说的话是工作室）~~ 带我的前辈说好多都是套壳公司。||享受政策红利的那种😓||
走下来挺有意思的~~(就是累麻了)~~。虽然说是跟着项目经理跑业务，主要是听经理和客户坐下来谈。培训时想过词元天下的业务逻辑||实际的和我想的差不多||，去线下确认，算这次的一个收获。
说说我对这套业务逻辑的理解吧~~(下面是不一定准确的主观暴论)~~：走访企业主要是开展词元天下的订单和业务。上面也提过，词元天下是一个聚合平台||本质中转站||。
业务大概分三块：

一个是租借服务器——客户在算力服务器上部署大模型，在数据保密的基础上用 LLM 提效率。考虑到安全和行业情况，或许会有这类场景||可能就银行之类的？我不道啊😵‍💫||，但依旧少见：一方面大模型去推生产力，感觉还没到每个行业都大规模用的地步；另一方面对数据保密和信息安全要求高的，确实比较小众。

剩下两块是他们主要推的。第二块也从算力出发，不过算力服务器是他们自己用，拿来部署开源大模型，再当聚合平台对外卖 API Key（总之就是 URL 接到词元天下这边，用的也是市面上比较新的开源模型。卖点可能便宜一点，或者有财政补贴和折扣）。

再一块就是纯中转站。可能的场景：产业园里好多企业对同一个大模型需求都不少，平台整合需求、以量取胜，去找模型提供方要折扣，政府或许再给一档折扣，拿到一个更低价的 API||我的理解主要是吃补贴吧，哈哈||

---

最后一部分是走访的企业，主要是一些小工作室（体量小可能更看重，所以会聊得具体一点）。他们会跟我们聊自己的项目和业务，算是了解一下行业现状~~（虽然也没什么用哈哈）~~。

首先是一家投资公司，做 POC 孵化器的。（这词我以前没接触过，了解一下。）当时脑子主要在想电信的业务逻辑，对他们了解很有限。||基本没有装到我的脑子里||
![](/content/stay/image-05.png) ![](/content/stay/image-06.png)

还有一家四五个人的游戏公司，主要拿 Codex 在做。看着用量挺凶，企业侧我不确定。项目是一个游戏平台，界面有点像抖音，里面有游戏给用户玩；也可以用聊天的方式定制想要的游戏，再发布到他们平台上。还在开发，8 月底估计进几千人内测。后续盈利大概也是包装成中转站去卖 Key：测试阶段允许用户自接 Key，正式上线后想做平台直充，再往后或许像抖音 / B 站那样做创作者激励。||下来之后我问了下前辈，他并不看好：首先他们用 GPT，这边大模型业务可能推不出去；要合作，大概率只是把社区推荐到词元天下的应用上。可我们这是小城市，推一个平台本来就难，第一波流量未必起得来||

![|211](/content/stay/image-07.jpg)

还有一家 AI 漫剧公司，挺有意思。||算是本地大学一个教授，带着学生的私活吧。||他们也做二次开发，而且挺完善——agent 就是他们自己用来做 AI 漫剧的。至少我看，这套平台还行。~~丑陋的 Web UI，主打一个能用就行。~~ 从剧情到剧本、分镜、画面整体设计，挺细。虽说都是视频生成，AI 漫剧和广告短片（好像还有一两个分类，想不起来了）是分开的，用不同 skill。印象深的是用量很大：负责人||也就是那个教授||说他们用字节的模型（火山引擎），||差不多一秒 0.98，按一块钱估，一部 120 分钟的 AI 短剧大概两万左右；基本做不到片子直出，改一改可能四五万||。业务好的时候一个月模型消耗差不多八九万（两部片的样子）。他们不是直接找红果这类平台对接，而是交给中间公司，再由对方去对接。||听他说，类似的中间公司也倒闭了好多|| 我感觉 AI 短剧挺火，出现不久就涌进很多人——有工具、又懂作品，确实能用对话方式干活。||前提是收入能盖过模型消耗|| 但他们也说平台那边可能压着不少未上架片子。这个行业我可以再多观察、多想想。

最后是一家无人机公司，工作室挺大~~(堆了一些硬件，有点像仓库)~~。
![|252](/content/stay/image-09.jpg) ![|253](/content/stay/image-10.jpg)
||他们那个洞洞板我超级喜欢，简直是我理想中的样子。||
业务需求是用大模型做无人机巡检 / 巡逻分析。他们有交通之类的订单，能提供设备，以及无人机拍下来的视频流。
||这可能涉及隐私、安全什么的。不过我感觉他们不太会本地部署，毕竟经费摆在那儿。|| 然后用大模型处理视频流，做智能预警。我觉得有难度：巡检路线不一定固定，场景里还可能有鸟之类的，不太好建模处理。
以前我个人看法是：大模型走 API Key / URL，很难落到物理层，响应会有延迟——可能因为我走的都是官方接口，服务器离得远，体感就慢。接到物理层的感受就是慢。||我个人看法是有点困难，不太做得了，但企业侧可能不好说。||
